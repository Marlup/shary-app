# Cross-Domain Use Cases Placeholder

## Purpose

This folder is reserved for future application-layer use cases that span
multiple current submodules and do not belong cleanly in `cloud/`,
`connector/`, or `security/`.

## Current state

- The folder is currently empty.
- Do not assume a missing implementation problem from the empty directory.

## Placement rule

Use this folder only when a use case genuinely coordinates multiple domains and
would become misleading if stored inside a narrower module.

## Update triggers

Update this README when:

- the first cross-domain use case is added;
- the placement rule changes.
