# Archive

Historical detailed reports and deprecated design/test material are stored here after consolidation into active docs.

- `implementation-reports/`: granular feature/change reports.
- `alignment-reports/`: point-in-time backend/frontend alignment status notes.

Active canonical docs live outside archive and are linked from `docs/README.md`.
